# TEHRAN Foodtruck

A minimal, responsive German landing page for TEHRAN Imbiss in Darmstadt.

## Cloudflare Pages

- **Framework preset:** None
- **Production branch:** `main`
- **Build command:** leave empty
- **Build output directory:** `/` (repository root)

This is a zero-build, dependency-free static website. All content lives in `index.html`; styling in `styles.css`; navigation and menu interactions in `app.js`.

## Updating content

- Replace illustrative photography with genuine restaurant photos before launch.
- Update food categories and copy in `index.html` and `app.js` once the confirmed menu and prices are available. No unconfirmed dish prices have been invented.
- Verify opening date, business hours and contact information before going live.

## Accessibility and privacy

Responsive layout, keyboard navigation, contrast, accessible mobile menu and reduced-motion support. No tracking scripts. The sample editorial food photographs are remotely loaded from Unsplash and should be replaced with first-party assets for production privacy and visual accuracy.
